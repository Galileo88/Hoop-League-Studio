Edge showing a download warning?

Edge may warn that HLS “isn’t commonly downloaded” because the installer isn’t widely recognized yet.

If you downloaded HLS using the button above, you can keep the installer: open Edge’s Downloads, click the three dots (…) beside the file, and select Keep. If another warning appears, select Show more, then Keep anyway.

Mac showing an “Apple could not verify” warning?
