# Hoop League Studio

Hoop League Studio is a league editor for **Hoop Land**. Create a new Pro or College league, customize an existing league, and export a finished league file to use in the game.

[Open Hoop League Studio](https://galileo88.github.io/Hoop-League-Studio/) to use the editor in your browser or find downloads for Windows and Mac.

## Build your league

- **League settings:** Create Pro or College leagues and customize their settings and awards.
- **Teams:** Add teams and edit their names, colors, logos, uniforms, and courts.
- **Players and rosters:** Manage team rosters and customize player appearances and ratings.
- **Staff and officials:** Edit coaches, referees, and announcers.
- **League images:** Use the Image Archive to manage logos, court images, and advertisements.

## Get started

1. Choose **New League** to start a league, or **Import League** to open an existing Hoop Land league file.
2. Customize your league, teams, players, and artwork.
3. Open **Save / Load League** to save your progress in one of three slots or continue a saved league.
4. Select **Export .txt** to download your league file for use with Hoop Land.

## Save and export

Saved leagues are stored locally in the browser or desktop app you use. Return to the same app or browser to continue editing through **Save / Load League**.

Export a copy of important leagues to keep a backup or move them to another device. Use **Import League** to open an exported league again.

Hoop League Studio is a community tool for creating and customizing Hoop Land leagues.
